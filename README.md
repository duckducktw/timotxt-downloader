# timotxt-downloader

把 **提莫書屋**（timotxt.com）的小說下載成乾淨 txt，離線閱讀。

## 這工具解決什麼問題

提莫書屋用**自訂字體反爬**：網頁把約 150 個常用字替換成諺文等罕用碼位，
再靠 `@font-face` 的自訂字體 `bqg` 在瀏覽器裡渲染回正確字形。

直接抓 HTML 只會得到一堆亂碼，例如：

```
廣播聲놇電梯里回蕩。眾그紛紛抬頭看了眼껗空
```

（`놇`=在、`그`=人、`껗`=上…）

本工具下載那個反爬字體，建立「碼位 → 真實中文字」對照表，解碼後輸出乾淨的 txt。

## 用法

```bash
python3 timotxt_dl.py <book_id> [-o output.txt]
```

`book_id` 是書本網址 `/<book_id>/dir` 裡的那串數字：

```
https://www.timotxt.com/0704594194/dir   ->   book_id = 0704594194
```

範例：

```bash
python3 timotxt_dl.py 0704594194
# 產生：末世：今天我又被迫復活.txt （296 章，約 60 萬字）
```

選項：
- `-o, --output` 指定輸出檔名（預設用書名）
- `--delay` 每章下載間隔秒數（預設 0.6，別調太低以免被擋）

## 解碼原理與兩種模式

工具會自動從頁面 CSS 找出反爬字體，然後：

1. **內建已驗證映射**（預設）：倉庫附了 `f24092.woff2` 與人工校對過的
   `map.json`（149 字，交叉驗證無誤）。只要網站用的是同一支字體（位元組一致），
   直接套用，100% 正確、零依賴。

2. **像素比對自動還原**（fallback）：若網站換了新字體，工具會把每個反爬字形
   渲染出來，和系統的 Noto CJK / 文泉驛字體做像素比對自動配對。這條路需要額外依賴
   （見下），且極少數簡繁/異體字可能有誤差，建議抽查。

## 依賴

內建映射模式只需 Python 3 標準庫，**零第三方依賴**。

自動還原模式（換字體時才會用到）需要：

```bash
pip install fonttools brotli pillow numpy
# 以及系統 CJK 字體（Debian/Ubuntu）：
sudo apt install fonts-noto-cjk
```

## 檔案說明

- `timotxt_dl.py` — 主程式
- `map.json` — `f24092` 字體的已驗證解碼表（碼位十六進位 → 中文字）
- `f24092.woff2` — 對應字體，用來比對網站是否仍用同一支

## 注意

- 本工具僅供**個人備份／離線閱讀**用途。請尊重原作者與網站權益，勿散佈盜版。
- 網站結構若改版，解析規則可能需要調整。
